# Toy kernel example

This is a **smoke test**, not a benchmark case and not a claim about any RTL
design. It exercises the kernel on a synthetic obligation graph:

- a declared TCB front-end (`O0`);
- a `REPLAY` leaf with a bound log;
- a checked polynomial identity;
- checked SMT implication nodes;
- a coverage obligation;
- a reused source-model invariant with a checked transfer;
- a checked root composition.

Run it from the PCD root:

```bash
./pcd check --case examples/toy/case.json --proof examples/toy/proof.json
```

Expected: `ACCEPT`, leaf `REPLAY`, composition `CHECKED`, TCB `O0`.

The SMT scripts are deliberately simple, but they are not arbitrary: each one is
the canonical encoding of the node's premise and goal formulas, regenerated by
the kernel. Editing a script without changing the corresponding formula is
rejected. See [`../../docs/05-ir.md`](../../docs/05-ir.md) for the expression language and limits.

To see a rejection, edit a copy of `proof.json` (for example, remove an entry
from `targets[0].requires`) and rerun. The kernel should reject with `K6`.
